# Unmounted canonical PD staging composition — development-only

This PR extracts `internal/pdstaging/stage.go` and existing unit tests from Draft #115 `c262173ded398372caeed0aa32e656d5f7283e60` onto `main@7bda7dc79ad25247fb85f73523195f25986df58f`. No CLI, executable worker, routing/service registration, Kubernetes Role/ServiceAccount, external JobSet schema, migrations or finance code is added.

**Caution: `StageInertPDJobSet` is an exported composition entry that can issue a real Kubernetes JobSet CREATE when directly invoked with working credentials. It is NOT read-only and must NOT be exposed to an untrusted tenant, Agent, generic Provider dispatcher, HTTP endpoint or production worker without separate acceptance.**

The helper `stageWith` starts at the already merged #163 `WithCurrentPDStagingFence`: it receives an independently source-checked, locked IN_FLIGHT reserved PD Operation and exact immutable DB PD snapshot, then creates a constrained `PDJobSetPlan` and `provider.Request` that must match Tenant/Project/Workload/Pool/Provider/Intent/Generation, canonical Operation ID/digest/idempotency and one-GPU-per-replica phase shape. It opens #162's UID-pinned unmounted GET/CREATE adapter using the operator-provisioned CA/token and restricted PostgreSQL UID-binding login, and verifies that the returned ACK matches the canonical request. Errors propagate into #163's UNKNOWN/inspect-first persistence, never a blind POST retry. The unmounted helper itself does not activate/unsuspend a JobSet or mark a GPU Allocation READY/RELEASED.

Included tests use a fake side-effect writer plus a fake fence to test mapping, config and source drift, wrong ACK and lost response; real database locking is tested independently in merged #163. **Neither fake tests nor this split prove the composition with real Kubernetes JobSet/Kueue/AdmissionGatedBy or its ServiceAccount RBAC.** Controller acceptance work is [PR #164](https://github.com/avaargsh/compute-control-panel/pull/164) Draft. Cross-service PostgreSQL+Kubernetes opt-in golden tests and physical driver evidence remain in the original #115 Draft.

**Merge as a library only** on exact-head full Go/vet/race/SIGKILL, real PG source-pinned release/receipt fences and Evidence. Require separate real controller KIND, independent current source and scoped credentials, replay/recovery and full hardware NodePrepare/Unprepare before any production activation, G04/G05 or cost FINAL claim.
